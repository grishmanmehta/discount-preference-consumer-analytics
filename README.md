# Decoding Discount Preferences in the Apparel Industry

An integrated analytics framework combining Conjoint Analysis, Structural Equation Modeling (SEM), K-Means Clustering, and Logistic Regression to understand consumer discount preferences, identify behavioral segments, and predict purchase likelihood.

## Key Objectives

* Identify discount attributes that influence consumer choice.
* Model psychological drivers using the Theory of Planned Behavior.
* Segment consumers into homogeneous groups.
* Predict purchase likelihood using behavioral and preference data.
* Develop an integrated framework for marketing analytics.

## Techniques Used

* Conjoint Analysis
* Exploratory Factor Analysis (EFA)
* Confirmatory Factor Analysis (CFA)
* Structural Equation Modeling (SEM)
* K-Means Clustering
* ANOVA
* Logistic Regression
